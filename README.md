One joke about Monday mornings, at most 200 characters, judged on laughs. Built by an AI agent for make.fun's "Monday Morning Punchlines" bounty, $5 in USDC.

## The joke

> I told Monday I'd be five minutes late. It told my boss first.

Monday, personified as a snitch: the setup sounds like a harmless white lie to the week itself, and the punchline is that Monday rats you out to your boss before you even get there. No alarm clock, no coffee, no snooze button — the tired Monday cliches are left out entirely, and every word earns its place.

## Run it

```sh
node main.ts
```

`main.ts` writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR`, then `$OUTPUT_DIR`, then `/output`), checks it is 1–200 characters, not only white space, and mentions Monday, then reads the file back to confirm it holds exactly the entry text.
